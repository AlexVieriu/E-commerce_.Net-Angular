You are helping me automate the conversion of markdown Q&A files into Anki-importable .txt files.

## Context
I have a Python script called `md_to_anki.py` in `skinet/questions/anki/`. It parses structured markdown files and outputs tab-separated Anki card files.

## What the script does
- Reads a markdown file with questions formatted as **B1.**, **A3.**, etc.
- Extracts only the <details><summary>Answer</summary> block (ignores Deep Dive)
- Auto-detects the sprint from the parent folder name (e.g. `sprint-1-interview` -> Sprint 1)
- Auto-detects the section from the filename (e.g. `section-b-*` -> Section B)
- Outputs a .txt file with this format:
  - Front: S02.01.Easy. [question with inline HTML formatting]
  - Back: HTML with bullet points, bold, inline code

## Output location
Each _anki.txt file is saved in an `anki/` subfolder inside the same sprint interview folder as the source .md:
  - sprint-1-interview/anki/section-a-csharp-dotnet_anki.txt
  - sprint-2-interview/anki/section-b-efcore-concurrency_anki.txt

The `anki/` subfolder is created automatically if it does not exist.

## Deck structure
Cards are assigned to a nested Anki deck built from the file path:
  #deck:E-Commerce - Sprints::Sprint N::Section X

This produces the following hierarchy in Anki:
  E-Commerce - Sprints
    Sprint 1
      Section A
      Section B
      ...
    Sprint 2
      Section A
      ...

## Your task
1. Look at the sprint interview folders and find all markdown files that follow the pattern `section-X-*.md`:
   - skinet/questions/sprint-1/sprint-1-interview/
   - skinet/questions/sprint-2/sprint-2-interview/
2. For each file found, run: `py skinet/questions/anki/md_to_anki.py <filepath>`
3. The output _anki.txt files will be created automatically in <sprint-folder>/anki/
4. After running all files, list the output files and confirm how many cards were generated per file

## Expected output filename format
section-a-csharp-dotnet.md     -> sprint-1-interview/anki/section-a-csharp-dotnet_anki.txt
section-b-efcore-concurrency.md -> sprint-2-interview/anki/section-b-efcore-concurrency_anki.txt

## Validation
After generating, open each _anki.txt and verify:
- First line is #separator:tab
- Fourth line is #deck:E-Commerce - Sprints::Sprint N::Section X
- First card front starts with the correct prefix (e.g. S01.01.Easy.)
- Back contains HTML tags (<ul>, <li>, <b>, <code>)
- No card has an empty back field

Report any issues found.
